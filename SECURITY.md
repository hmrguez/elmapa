# Reporting a security issue

Report suspected vulnerabilities privately through the repository's [security advisory form](https://github.com/hmrguez/elmapa-public/security/advisories/new). If the form is unavailable, open a public issue titled “Request for private security contact” and wait for a maintainer to arrange a private channel before sharing technical details.

In the private report, include the Elmapa version or commit, operating system, affected feature, expected behavior and observed impact. If an atlas, SVG or landmark pack is involved, share a minimal example you created for the report. Remove personal paths, credentials and unrelated map content.

Maintainers use the private report to investigate the affected versions and coordinate a fix and disclosure with the reporter. For crashes or rendering bugs with no suspected security impact, use the [ordinary bug report](https://github.com/hmrguez/elmapa-public/issues/new/choose).
